# OrderFlow API

REST API for order and inventory management, built as a reference project for professional Java backend engineering.

> Development is starting. The complete project structure and documentation will be introduced through pull requests.

## Planned stack

Java 25, Spring Boot 4.1, PostgreSQL 18, Flyway, Maven, Docker Compose, JUnit and Testcontainers.

## Roadmap

1. Foundation, development environment and CI.
2. Product catalog and persistence.
3. Inventory and transactional orders.
4. Security and idempotency.
5. Observability and containerization.
6. Documentation and final engineering review.
